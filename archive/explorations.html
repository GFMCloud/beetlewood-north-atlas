Interactive tree of life. The taxonomic hierarchy on the property, class → genus → species, laid out as a radial tree. The production build inserts the order and family rings from the iNaturalist taxonomy API.
Brain map. Taxonomy mode wires each genus to its class — the same structure as the tree, as a force graph. Switch to seasonal co-occurrence to link genera he logs on the same days: clusters are things that show up together in the field, which the tree can't show.
